# AGENTS.md

Files under `.agents/` are agent-facing support material.

- Keep this subtree platform-agnostic unless a file explicitly documents a runtime-neutral convention.
- Do not add credentials, local transcripts, generated logs, package caches, or temporary evidence here.
- Skills are non-authoritative aids. They must point back to the root `AGENTS.md`, accepted ADRs, and stable reference documentation instead of redefining them.
