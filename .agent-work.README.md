# `.agent-work/` local workspace convention

`.agent-work/` is an ignored, non-authoritative local workspace for temporary evidence, interrupted work, and handoff-sensitive notes.

Suggested layout:

```text
.agent-work/
  evidence/      # command summaries, screenshots, copied snippets, or local observations
  handoff/       # notes needed if work is interrupted before a clean stopping point
  scratch/       # disposable experiments that should not be committed
```

Rules:

- Do not commit `.agent-work/` contents.
- Do not treat `.agent-work/` notes as repository authority.
- Do not store credentials, secrets, raw package caches, local SDKs, or large generated artifacts.
- Summarize relevant evidence in the final report or durable docs instead of committing local transcripts.
