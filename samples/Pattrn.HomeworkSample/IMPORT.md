# Homework import provenance

This sample imports the Homework application, tests, benchmark, documentation,
and images from local source commit
`9c06265ef4424ed86691e088f563325ea1fa3d08` for the Pattrn subscription-index
evaluation.

The repository maintainer explicitly authorized this experimental copy. Original
copyright and proprietary notices are preserved. This import does not claim that
the copied Homework material was relicensed under Pattrn's MIT license.

Generated build outputs, BenchmarkDotNet artifacts, caches, and the source
repository's Git metadata are intentionally excluded.
